# Lingo

A deployable starter kit for multilingual meetings.

Lingo puts live translated captions, speaker attribution, a translated transcript after the call, and accessible exports in one kit. A participant can follow the meeting in another language while it is happening, and the same meeting can be exported afterwards as a transcript that names who said each line.

## Status

This repository is being initialized. There is nothing to deploy yet. The kit, its configuration, and setup steps will be added as they are built.

## What it covers

- **Live translated captions** while the meeting is running.
- **Speaker attribution**, so each line stays tied to the person who said it.
- **Post-call translated transcripts** for the languages you request.
- **Accessible exports** of the captions and the transcript.

## Repository scope

- A starter you can deploy for a multilingual meeting.
- Configuration for the spoken language, the caption languages, and the export format.
- Docs for running it against a MeetStream bot once the kit is ready.

## About MeetStream

[MeetStream](https://meetstream.ai) is meeting bot infrastructure. A bot joins Google Meet, Zoom, or Microsoft Teams, records the call, and returns a transcript with speaker attribution through an API.
